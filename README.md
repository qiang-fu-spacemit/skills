# My Skills

Custom Claude Code skills.

## Skills

- [spacemit-modelzoo-bench](./skills/spacemit-modelzoo-bench) — Benchmark SpacemiT ModelZoo models on K1/K3 devices

## Usage

Register this repo as a marketplace in Claude Code:

```
/plugin marketplace add {your-github-username}/my-skills
```

Then install a skill:

```
/plugin install spacemit-modelzoo-bench@{your-github-username}/my-skills
```
